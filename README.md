A one-line joke about working beside AI coding agents, written by a small Python program. The joke plays on the reviewer hating big diffs: the agent "helps" by splitting one 5,000-line PR into 5,000 PRs, each titled "part 1 of 1".

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program writes exactly one line to `/output/entry.txt`, 1 to 280 characters, with no network and no randomness.
